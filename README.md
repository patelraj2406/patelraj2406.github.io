# Raj Patel — Portfolio Website

A 7-page personal site: Home, About, Education, Experience, Projects, Certifications, Contact.

## How to publish this on GitHub Pages

1. Go to github.com and create a new repository named exactly:
   `patelraj2406.github.io` (must match your GitHub username exactly).
   Make it **Public**.

2. On the new repo's page, click **Add file → Upload files**.

3. Drag in every file from this folder:
   - `index.html`
   - `about.html`
   - `education.html`
   - `experience.html`
   - `projects.html`
   - `certifications.html`
   - `contact.html`
   - `style.css`

4. Scroll down, write a commit message like "Initial site," and click **Commit changes**.

5. Go to **Settings → Pages** (left sidebar). Under "Source," choose branch
   `main` and folder `/ (root)`, then **Save**.

6. Wait 1–2 minutes, refresh that Pages settings screen. Your live link will
   appear — something like:
   `https://patelraj2406.github.io`

## Making changes later

Click any file in the repo → the pencil (edit) icon → make changes → commit.
GitHub Pages rebuilds automatically within about a minute.

## Notes

- All contact details (email, phone, LinkedIn, GitHub) are pulled from your
  resume — double check they're current before publishing.
- The Projects page currently has one entry (the IoT watering system). Add
  more `.project-card` blocks to `projects.html` as you build new things —
  just copy the existing block and swap the content.
- Fonts (IBM Plex Mono / IBM Plex Sans) load from Google Fonts automatically;
  no extra setup needed.
